# v1.3.4

聚焦悬浮字幕启动链路的一组修复:Android 10–13 上「应用内声音」授权后开关自动回弹的主问题,以及它牵出的四个连带问题。

---

## 修复

### 悬浮字幕 · 应用内声音(Android 10–13)

- **授权后开关几秒自动关闭、反复要求重新授权**(#2):授权流程本身是成功的,但应用在 Android 10–13 上没有把已授权的屏幕录制凭证兑换成实际的音频投射实例,启动时误判为「未授权」直接拒绝开启浮窗。表现为:选「应用内声音」并完成授权后,开关短暂显示开启,几秒后自动跳回关闭。现在低版本与 Android 14+ 走同一条兑换路径,应用内声音在 Android 10–13 上恢复正常

### 界面与交互

- **切走应用再回来,开关显示「已关闭」但字幕其实还在翻译**:开关状态此前只做「服务停止 → 关闭」的单向同步,界面重建后不会从后台状态回填。现在开关初值直接取自运行状态,重建后如实显示
- **非首次安装时,每次冷启动都闪一下引导页**:引导页标记是异步读取的,旧逻辑在数据到达前默认按「显示」渲染首帧,约 0.6 秒后才切到主界面。现在数据未就绪时只显示纯背景色,不再闪引导页;全新安装的正常引导流程不受影响

### 启动与停止

- **ASR 模型加载期间关闭浮窗,误报「请先授权屏幕录制权限」**:模型加载耗时可达数秒(真机实测约 2.1s),期间关闭浮窗后,启动流程恢复时会读到已被释放的投射实例,误判为未授权并弹出错误提示——而用户明明已经授权过。现在启动流程会在继续前确认浮窗仍处于开启状态,期间被关闭则静默退出
- **浮窗关闭时,聊天输入栏的麦克风点了没反应**:上一条修复的退出守卫没有区分「浮窗启动」与「语音输入启动」两条路径,导致浮窗关闭时语音输入被静默拦截、无任何反应。本次一并修正

### 其它

- 英文界面补齐 3 条 API 配置相关的缺失文案(顺带解除了 CI 的存量 lint 阻塞)
