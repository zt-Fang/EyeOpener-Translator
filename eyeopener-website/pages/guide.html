引导流程

1

欢迎页

打开 EyeOpener 后，你会看到欢迎页面，展示三大核心功能亮点。点击"开始了解"即可进入配置流程，也可选择跳过直接进入主界面。

首次使用建议跟随引导完成基本配置
2

语言选择

选择源语言（识别）和目标语言（翻译）。点击语言卡片即可选择，再次点击确认。

A
可以访问 Google

极速翻译模式，设备端引擎，速度快延迟低

B
无法访问 Google

AI 智能模式，需前往「设置 → API 设置」配置大模型

30+ 种语言离线识别 70+ 种语言翻译对
3

开启悬浮字幕

完成语言配置后，在首页点击大开关，授予悬浮窗和麦克风权限即可开始实时字幕翻译。悬浮窗支持拖拽移动、缩放调节，可随时在右上角设置中个性化字幕外观。

设置入口

本地模型

下载和管理语音识别模型（30+ 种语言）及高质量翻译模型。首次使用需联网下载。

API 设置

配置 AI 翻译的大模型服务商、API Key、Base URL 等参数。用于 AI 智能翻译模式。

个性化设置

字幕颜色、字体大小、透明度、显示模式等视觉定制。让字幕适应你的阅读偏好。

历史记录

查看、收藏、删除、导出翻译历史。支持按时间浏览和快速搜索。

使用技巧

翻译保护

翻译进行中无法删除模型 — 系统保护机制，请先停止翻译再管理模型

VAD 语音检测

3 秒无声音时会出现提示，表示正在等待语音输入

离线翻译

下载模型后无需网络即可使用识别和翻译功能

降级策略

当前引擎超时或网络异常时自动切换到极速模式
